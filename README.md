## 📊 Selected projects

### [Customer Churn Prediction](https://github.com/AbhishekJG/customer-churn-prediction)
End-to-end churn classification on a telecom dataset (3,300+ records, 20 features): data preparation, class-imbalance handling and a comparison of five algorithms. **XGBoost reached 92% accuracy**, identifying service-call frequency and usage as the main churn drivers. A Tableau dashboard turns the findings into retention recommendations.

**Tools:** Python, Scikit-learn, XGBoost, Tableau

### [Cloud Monte Carlo Simulation for NVIDIA](https://github.com/AbhishekJG/monte-carlo-nvidia-var)
Ran **5,000 Monte Carlo simulations** on AWS EC2 and Lambda to estimate NVIDIA's **95% Value at Risk**, storing results in S3 and serving risk metrics through an API on Google App Engine.

**Tools:** AWS EC2, Lambda, S3, Google App Engine, Python

### [Database Optimisation and BI for Mumsnet](https://github.com/AbhishekJG/mumsnet-sql-ssas)
Normalised a SQL Server database to third normal form and built SSAS cubes and dimensions for multidimensional analysis.

**Tools:** SQL Server, SSAS, database design

### [E. coli Protein Localisation Prediction](https://github.com/AbhishekJG/ecoli-protein-localisation)
Built classification models to predict protein localisation, using feature distributions, correlation heatmaps and confusion matrices to explore the data and explain model errors.

**Tools:** Python, Scikit-learn, Pandas, Matplotlib, Seaborn
